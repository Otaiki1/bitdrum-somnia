# BitDrum Frontend

The BitDrum frontend is a high-performance web and mobile interface designed to provide a premium trading experience on Starknet.

## Role in the System
- **Trading Dashboard**: Live market feed and interactive price charts.
- **Social Dashboard**: Leaderboards, trader profiles, and follow feeds.
- **AI Sidebar**: Real-time signals and POM profit displays.

## Stack
- Next.js 14 / React Native (Expo)
- Starkzap SDK (Auth, Paymaster, Contracts)
- Tailwind CSS / shadcn/ui (Premium Glassmorphism Design)
- TradingView Lightweight Charts
